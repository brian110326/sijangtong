# 🛒 Sijangtong (시장통)

팀 프로젝트로 진행한 쇼핑몰 웹 애플리케이션입니다.  
소비자가 다양한 상품을 검색하고 구매할 수 있는 기본적인 기능을 포함합니다.

## 📌 주요 기능

- 회원 가입 및 로그인  
- 상품 목록 조회 및 상세 페이지  
- 장바구니 기능 (상품 추가/삭제)  
- 주문 처리 및 결제  
- 관리자 상품 관리 (등록, 수정, 삭제)  
- 상품 검색 및 필터링

  ## 🔧 기술 스택

- Java  
- Spring Boot  
- Spring Security  
- Spring Data JPA  
- QueryDSL  
- Thymeleaf  
- MySQL    
- Maven

## 👤 담당 역할

본 프로젝트는 팀 단위로 진행되었으며,  
저는 프론트엔드 개발자들이 데이터를 원활히 받을 수 있도록  
JPA와 QueryDSL을 활용해 백엔드 개발을 담당했습니다.
